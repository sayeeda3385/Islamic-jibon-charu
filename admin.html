প্রাথমিক সংযোগ বাকি

প্রথমে supabase-config.js-এ Supabase Project URL এবং Publishable/anon key বসাতে হবে। এরপর supabase-setup.sql নির্দেশনা অনুসারে Auth user, টেবিল ও Storage policy তৈরি করুন।

কখনোই service_role key এখানে বা GitHub-এ যোগ করবেন না।

অ্যাডমিন লগইন

শুধু আগে থেকে Supabase Auth-এ তৈরি করা অনুমোদিত অ্যাডমিন অ্যাকাউন্ট ব্যবহার করুন। এখানে নতুন অ্যাকাউন্ট খোলার সুবিধা নেই।
