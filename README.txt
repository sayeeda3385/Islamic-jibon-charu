ইসলামিক জীবন — চারু V2

এই সংস্করণে:
- হানাফি পদ্ধতিতে প্রাথমিক নামাজ শিক্ষা
- বাংলা/English UI toggle
- দৈনন্দিন দোয়া ও নির্বাচিত সূরা
- ১১৪টি সূরার অনলাইন তালিকা
- প্রতিটি সূরার Uthmani Arabic text, Bengali translation এবং Mishary Alafasy recitation audio
- আগে খোলা HTML/কিছু API text offline cache হওয়ার ব্যবস্থা

কুরআন ডেটা:
AlQuran Cloud API: https://alquran.cloud/api
Arabic edition: quran-uthmani
Bengali translation edition: bn.bengali
Audio edition: ar.alafasy
Audio CDN documentation: https://alquran.cloud/cdn

সীমাবদ্ধতা:
- সম্পূর্ণ কুরআনের পাঠ/অনুবাদ/অডিও প্রথমবার আনতে ইন্টারনেট লাগবে।
- সব সূরা আগে থেকে ডাউনলোড করা হয় না; যে সূরা খোলা হয়েছে তার টেক্সট cache হতে পারে।
- অডিও ফাইল অফলাইনে cache করার নিশ্চয়তা নেই; ব্রাউজার স্টোরেজ ও নেটওয়ার্ক নীতির ওপর নির্ভর করে।
- পূর্ণাঙ্গ ফতোয়া/মাসআলা অ্যাপ নয়। হানাফি নামাজ নির্দেশনা সাধারণ পরিচিতি; প্রকাশের আগে যোগ্য আলেমের যাচাই প্রয়োজন।
- অনুবাদ মূল আরবি কুরআনের বিকল্প নয়।
